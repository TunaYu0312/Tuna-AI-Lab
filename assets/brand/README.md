# Tuna AI Lab 品牌资产

本目录保存 Tuna AI Lab（金枪鱼 AI 实验室）的 Logo 原稿、当前正式 Logo 和机器可读清单，供文档、项目页面、应用界面与后续品牌衍生设计统一引用。

## 当前正式 Logo

正式 Logo 使用第 4 号方案：金枪鱼轮廓、数字电路纹理、深海军蓝背景，以及青色与白色的 `Tuna AI Lab` 字标。

统一引用路径：

```text
assets/brand/logos/official/tuna-ai-lab-logo-primary.png
```

该文件是第 4 号候选原图的字节级副本。候选原稿仍保存在：

```text
assets/brand/logos/concepts/tuna-ai-lab-logo-concept-04.png
```

## 使用规则

- 正式文档、仓库首页、项目介绍和应用品牌页面默认使用 `official/tuna-ai-lab-logo-primary.png`。
- `concepts/` 仅用于设计回顾、方案比较和未来迭代，不作为对外正式标识。
- 不拉伸、不压扁、不旋转正式 Logo，不在原图上直接覆盖项目名称。
- 项目或应用需要衍生 Logo 时，应另建子目录保存，不覆盖正式 Logo。
- 当前正式文件为带深色背景的正方形 PNG，适合封面、头像和品牌展示；小尺寸应用图标、透明背景、水印和矢量印刷场景仍需后续制作专用版本。
- 仓库中的代码许可（如未来添加）不自动代表 Logo 或品牌标识可被第三方自由使用；对外授权需单独确认。
