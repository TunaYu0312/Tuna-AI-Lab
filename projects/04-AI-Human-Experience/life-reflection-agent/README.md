# Life Reflection Agent

## 定位

一个非宗教、非诊断的人生反思助手。通过开放式问题帮助用户理解过去、审视现在，并为有限的未来选择更重要的行动。

## 核心理念

死亡教育不是渲染死亡，而是承认生命有限，从而珍惜当下、真实关系和个人梦想。

## MVP

- Past：关键人物、经历、选择与遗憾；
- Present：角色、关系、冲突与时间分配；
- Future：希望体验、创造、守护和留下什么；
- Life Map：价值排序、要放下的负担及下一步小实验；
- 支持暂停、跳过、编辑、导出和删除。

## 产品语气

温和、开放、不说教，不使用寿命倒计时或焦虑刺激，不提供唯一的人生答案。

## 不做

- 替代心理咨询或临终关怀；
- 给出宗教或哲学定论；
- 强迫用户披露创伤；
- 把人生意义量化成单一分数。
