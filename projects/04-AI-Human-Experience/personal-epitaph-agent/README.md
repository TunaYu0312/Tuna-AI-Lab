# Personal Epitaph Agent

## 定位

通过生命访谈设计 Living Epitaph（生前墓志铭）和 Life Manifesto（人生宣言）。

它不是提前准备死亡，而是从“希望如何被记住”反推“今天应该如何生活”。

## MVP 流程

1. 访谈童年、成长、家庭、工作、关系、创造、遗憾、价值与梦想；
2. 用户确认事实和隐私范围；
3. 提炼反复出现的人生主题；
4. 生成极简、家庭、哲思和纪念版本；
5. 转化为人生宣言和近期行动；
6. 支持编辑、版本保存、导出和删除。

## 质量标准

- 真实、克制，避免空泛赞美；
- 具体经历必须来自用户材料；
- 区分事实、用户解释和 AI 提炼；
- 输出不是最终定论，用户始终可改写。

## 不做

- 虚构人生经历；
- 未经允许评价人格；
- 利用死亡焦虑促销；
- 强迫披露创伤或隐私。
