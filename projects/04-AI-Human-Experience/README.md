# AI Human Experience

AI Human Experience 是 Tuna AI Lab 的 Human-Centric AI 项目群，研究 AI 如何帮助人觉察情绪、反思生命、保存真实记忆并建立意义。

## 项目

- [Emotion Pulse](emotion-pulse/README.md)
- [Digital Memorial](digital-memorial/README.md)
- [Life Reflection Agent](life-reflection-agent/README.md)
- [Personal Epitaph Agent](personal-epitaph-agent/README.md)

## 共同方法

```text
Problem → User Research → Ethical Review → Low-risk Prototype
        → Evaluation → Limited Pilot → Publish or Stop
```

## 共同边界

- 不进行医疗或心理诊断；
- 不预测寿命；
- 不模拟或“复活”逝者；
- 不使用未经授权的私人资料；
- 不用死亡焦虑、悲伤或内疚促进留存；
- AI 生成内容必须标识并允许用户修改或删除。

本方向目前为 P1 Backlog。进入开发前先完成用户研究、风险清单和四周 MVP 停止条件。
