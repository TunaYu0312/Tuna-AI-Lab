# Tuna AI Lab（金枪鱼 AI 实验室）

> 用 AI 增强人的认知与决策能力，解决真实世界中值得解决的问题。

Tuna AI Lab 是一个以真实问题为起点的个人 AI 应用实验室。这里不以收集技术名词或堆砌 Demo 为目标，而是持续完成“问题定义—开源研究—复现理解—场景改造—验证发布”的闭环。

## 项目方向

| 方向 | 目标 | 首批课题 |
|---|---|---|
| Decision Agents | 把经营数据转化为可验证的决策建议 | Pricing Agent、门店健康度、菜单工程 |
| AI Education | 帮助家庭改善 AI 时代的成长与学习决策 | Family Learning Navigator |
| LLM Application Lab | 沉淀可复用的大模型工程能力 | RAG、MCP、Tool Calling、Memory、Skills |
| Computer Vision | 建立视觉感知与零售场景实验能力 | OCR、YOLO、OpenCV、SAM2 |
| Robotics | 连接感知、推理和动作 | 摄像头、语音、对话、动作规划 |
| Open Source Research | 系统识别、复现和评估开源成果 | GitHub Radar、架构评审、技术雷达 |

## 工作原则

1. 先定义用户与问题，再选择技术。
2. 优先复现和理解成熟开源项目，不重复造轮子。
3. 严格遵守开源许可证，记录代码与思想来源。
4. 输出区分事实、推断和建议，并明确不确定性。
5. 每个项目都有完成标准和停止条件。
6. 小步提交，每周形成可检查的成果。

## 统一流程

```text
Problem → Research → Reproduce → Understand → Adapt → Evaluate → Publish
```
