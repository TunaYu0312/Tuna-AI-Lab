# Family Learning Navigator PRD v0.1

## 1. 问题

AI 正在改变知识获取和工作方式，但家庭缺少可信、可执行的框架来回答：孩子为什么学习、当前应优先发展什么、如何低成本探索而不被短期热点牵引。

## 2. 产品定位

一个家庭成长决策辅助工具，而非职业预测、心理诊断或“AI 教育专家”。它的目标是提高问题定义和探索质量，不替家长、孩子或专业人士做最终决定。

## 3. 用户

- 对 AI 时代教育方向感到困惑的家长；
- 具备表达和共同决策能力的青少年；
- 可选协作者：教师、辅导员和教育研究者。

首版建议聚焦一个年龄段，待用户研究后确定；不默认覆盖所有儿童。

## 4. 核心流程

```text
家庭问题定义
→ 收集行为与作品证据
→ 形成可修正的能力假设
→ 识别不确定性与约束
→ 提供多条探索路径
→ 设计四周小项目
→ 家庭共同选择
→ 记录结果并复盘
```

## 5. 输入

- 年龄阶段、学习环境和可投入资源；
- 孩子的兴趣陈述及具体行为证据；
- 学习经历、作品、困难和反馈；
- 家庭期待、价值取向与现实约束；
- 孩子本人对目标和建议的意见。

系统应允许“不知道”，不得通过暗示性问题制造虚假画像。

## 6. 输出

- 已知事实、信息来源和缺口；
- 暂定能力/兴趣假设及反证条件；
- 2–3 条可探索路径，而非单一答案；
- 每条路径的四周实践项目、资源、成本和观察指标；
- 家长行动与不应做的事情；
- 复盘问题和下一次调整日期。

## 7. BPRE 适配（待验证）

- B / Being：想成为什么样的人、重视什么价值；
- P / Portfolio：应积累的基础能力、AI 协作能力与作品；
- R / Route：课程、项目、社区和真实问题的组合路径；
- E / Economics：时间、金钱、机会成本和可持续性。

BPRE 是组织问题的假设框架，不应被当作已验证的儿童发展理论。需要与教育研究和真实用户反馈交叉验证。

## 8. 成功指标

- 用户能区分事实、推断和建议；
- 输出至少包含两条可逆的探索路径；
- 家庭能选出一个四周内可执行的行动；
- 复盘后建议可基于新证据修正；
- 专家评审未发现明显的年龄不当、标签化或有害建议；
- 系统不输出确定性职业、智力或人格结论。

## 9. 安全、隐私与伦理

- 默认最小化收集未成年人数据；
- 不收集不必要的姓名、学校、联系方式或精确位置；
- 家长同意不能取代孩子的参与和尊重；
- 不用于招生、淘汰、排名或高风险自动决策；
- 对心理健康、学习障碍等问题只建议寻求合格专业支持；
- 明确模型局限、偏差与信息时效。

## 10. 研究与里程碑

1. 访谈家长、青少年和教育从业者，验证问题；
2. 梳理教育与未来技能的可靠证据，建立来源等级；
3. 设计纸面原型和安全测试；
4. 完成最小可用网页流程；
5. 进行小规模家庭试用与四周复盘。

## 11. 停止条件

如果用户研究显示产品只增加焦虑、建议不可执行、无法控制标签化风险，或家庭不愿进行周期复盘，则停止自动建议功能，转为问题清单和人工工作坊工具。
