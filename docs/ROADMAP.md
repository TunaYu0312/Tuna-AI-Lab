# Tuna AI Lab 路线图

## 目标

用 90 天建立可持续的实验室运行机制，并完成两个可演示、可评估的 P0 原型。首阶段不平均推进六条路线。

## 第 1–2 周：基础设施

- 建立仓库结构、模板和项目准入标准；
- 建立 GitHub 项目雷达记录格式；
- 为两个 P0 项目确定用户、问题、边界和测试案例；
- 建立开源来源与许可证台账。

## 第 3–6 周：Pricing Agent MVP

- 准备合成或脱敏的菜单、销量、毛利和运营样本；
- 建立不依赖大模型的规则/统计基线；
- 形成诊断、建议、证据和风险四类结构化输出；
- 加入情景模拟和人工复核点；
- 完成 10 个测试案例和失败案例记录。

## 第 7–10 周：Family Learning Navigator MVP

- 通过访谈或公开研究校验家长的关键决策问题；
- 建立“证据—假设—建议”分离的数据结构；
- 生成多条可探索路径，而非确定性职业预测；
- 设计四周行动计划与复盘机制；
- 完成安全、偏差和过度推断测试。

## 第 11–12 周：发布与复盘

- 完成两个项目的演示、架构和评估文档；
- 复盘可复用组件，形成 Decision Agent 模板；
- 发布 90 天总结，决定下一周期继续、暂停或停止的项目；
- 从 Backlog 只选择一个新 P0。

## 12 个月方向（非承诺排期）

1. Decision Agents：定价、门店健康、顾客旅程；
2. AI Education：成长导航的迭代与验证；
3. LLM 工程：RAG、工具调用、MCP、评估、记忆；
4. Computer Vision：OCR 到门店巡检；
5. Robotics：在视觉和语音能力成熟后再接入硬件。

## 每月衡量

- 完成并可复现的实验数；
- 有明确测试结果的原型数；
- 记录清晰的失败实验数；
- 被复用的组件与模板数；
- 用户访谈/真实反馈数；
- 无来源代码和许可证风险数（目标为 0）。
